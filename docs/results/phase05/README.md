# Phase 0.5 Mechanistic Redesign

This directory preserves the official Phase 0.5 mechanistic-redesign
execution and its associated analysis.

## Status

**PHASE-0.5 TERMINATED AT STAGE I-A — FLOW MECHANISM GATE NOT ESTABLISHED**

Phase 0.5 was a staged mechanistic redesign following the Phase 0 result.
The first development stage tested whether continuous latent flow could
demonstrate a reproducible low-N advantage over no-flow dynamics in the
smooth synthetic development world.

The Stage I-A flow gate completed all 60 preregistered cells. Neither
candidate flow mechanism passed the locked development criterion.
Accordingly, later Stage I mechanisms were not entered, no architecture
was frozen, and confirmatory seeds were not used.

## Scientific boundary

The preregistered result is the Stage I-A flow-gate decision.

Post-gate inspection of N-specific predictive, event, and latent-state
metrics is exploratory diagnostic analysis. It may motivate Phase 0.6,
but it must not be interpreted as a post-hoc reversal of the official
Phase 0.5 decision.
