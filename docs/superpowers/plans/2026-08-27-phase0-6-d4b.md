# Phase 0.6 D4-B Optimization/Initialization Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the frozen Phase 0.6 D4-B initialization/optimization stability diagnostic, its analysis/adjudication, provenance boundaries, and guarded CUDA execution path without exposing any later D4 intervention.

**Architecture:** Extend the existing Phase 0.6 stage framework rather than creating a parallel runtime. D4-B gets a dedicated planner/analysis module and protocol-parent validator, reuses the existing cell runner/store/execution loop, binds to both immutable Phase 0.6 evidence roots, and writes into a distinct hash-bound child store. Execution and adjudication remain separate commands.

**Tech Stack:** Python 3.11+, PyTorch, pandas, NumPy, pytest, Ruff, Bash/tmux CUDA execution tooling.

**Spec:** `docs/superpowers/specs/2026-08-27-phase0-6-d4b-execution-addendum.md`

## Global Constraints

- Matrix is exactly 5 fixed cohort/subset contexts × model seeds `1001..1010` × `{none,time_scaled}` at `N=40` = 100 cells.
- Official D4-B execution is CUDA-only, one worker.
- Confirmatory cohort/subset/model namespaces `701..710` / `801..810` / `901..910` remain forbidden.
- D4-B must bind to both immutable parents: the core D1/D2-A/D3 root and the completed D2-B root.
- D4-B may not change optimizer, learning rate, weight decay, patience, epoch limit, objective, checkpoint policy, architecture, dimensions, time scale, data generation, split semantics, or budget selection.
- Bootstrap is model-seed-cluster resampling, 10,000 resamples, seed `20260827`, percentile 95% CI.
- Classification is frozen: stable iff overall mean >0, >=8/10 positive model-seed means, >=4/5 positive context means, and CI lower >0; fragile if overall mean <=0 OR <=5/10 positive seeds OR <=2/5 positive contexts; otherwise ambiguous.
- Only `d4b` and `adjudicate-d4b` may be added. No D4-D/full-factorial/confirmation path.
